# 📋 Projeto-Cadastro

Este projeto foi desenvolvido com o objetivo de otimizar a atualização de registros de pedidos em um banco de dados. Utilizando **Java**, **JDBC**, **MySQL** e **procedures armazenadas**, a aplicação permite que os usuários modifiquem facilmente informações como valores e datas dos pedidos. A interface gráfica foi desenvolvida com o **NetBeans**, focando em uma experiência de uso clara, objetiva e organizada.

---

## 🖥️ Interface Gráfica

A interface foi construída com Java Swing, permitindo a realização das seguintes ações:

- 🔍 Visualizar registros com apresentação formatada
- 📝 Criar, atualizar e deletar registros
- 📌 Buscar registros por código
- ✅ Apresentação clara e responsiva dos dados
